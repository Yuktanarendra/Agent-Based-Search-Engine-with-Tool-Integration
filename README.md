# 🔍 Search Engine with Tools and Agents

A **tool-powered AI search engine** built using **LangChain Agents**, capable of reasoning, selecting tools dynamically, and returning accurate, context-aware answers.  
This project demonstrates how **LLM agents** can orchestrate tools such as search, reasoning, and data extraction to solve user queries intelligently.

---

## 🚀 Features

- 🤖 **Agent-based Architecture**  
  Uses LangChain Agents to decide *which tool to use and when*.

- 🛠 **Tool Integration**  
  Integrates search and utility tools for enhanced question answering.

- 🧠 **Reasoning + Action (ReAct)**  
  The agent reasons step-by-step before taking actions.

- 🔎 **Intelligent Search Handling**  
  Retrieves relevant information instead of plain text generation.

- ⚡ **LLM-Powered Responses**  
  Combines tool output with LLM reasoning for final answers.

- 📊 **Traceable Execution Flow**  
  Each step (thought → action → observation → answer) is transparent.
